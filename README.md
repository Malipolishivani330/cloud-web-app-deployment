# AWS EC2 Nginx Web Application

## Project Description

This project demonstrates the deployment of a simple web application on an AWS EC2 instance using Nginx.

## Technologies Used

- AWS EC2
- Amazon Linux 2023
- Nginx
- HTML

## Deployment Steps

1. Created an AWS EC2 instance.
2. Configured the Security Group.
3. Allowed SSH access on port 22.
4. Allowed HTTP access on port 80.
5. Connected to the EC2 instance.
6. Installed Nginx.
7. Started and enabled the Nginx service.
8. Created a custom HTML web page.
9. Deployed the application using Nginx.
10. Accessed the application using the EC2 Public IP address.

## Application Status

Deployment completed successfully.

The web application is running on AWS EC2 using Nginx.
